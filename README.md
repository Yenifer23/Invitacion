# Invitación digital — Ana & More

Sitio estático hecho con HTML, CSS y JavaScript. No necesita base de datos ni servidor SQL.
La fotografía está incorporada dentro de `index.html`, por lo que el sitio funciona con ese único archivo.

## Ver en tu computadora
1. Abrí `index.html` con Google Chrome o Edge.
2. Para editar el código, abrí la carpeta en Visual Studio Code.

## Publicar con GitHub Pages
1. Creá un repositorio nuevo en GitHub.
2. Subí `index.html` a la raíz del repositorio.
3. Entrá en **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama `main` y la carpeta `/ (root)`, y guardá.
6. GitHub te mostrará la dirección pública del sitio en esa misma sección.

Cualquier cambio que hagas en `index.html` y subas a la rama publicada actualizará la invitación.
